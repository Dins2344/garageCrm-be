## Lock file matches CI

CI runs Node 20 / npm 10. A lock generated by a newer npm fails `npm ci` with
`Missing: <pkg> from lock file`, even though the local install worked.

```bash
npx -y npm@10 ci --dry-run
```

If it fails, regenerate with CI's npm and re-verify:

```bash
npx -y npm@10 install --package-lock-only
```
